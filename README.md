# Menu-Image-to-Excel
A simple tool that converts menu images into structured CSV files using a local 7B model via Ollama.

## 🚀 Features
- Image → CSV (Excel-ready)
- Runs locally (no cloud)
- Simple CLI usage

## 📦 Requirements
- Python 3.8+
- Ollama installed
- 7B model (e.g., `ollama run llama3`)

## ⚙️ Setup
```bash
git clone https://github.com/Saptarshi-Bagchi/Menu-Image-to-Excel.git
cd Menu-Image-to-Excel
pip install -r requirements.txt
